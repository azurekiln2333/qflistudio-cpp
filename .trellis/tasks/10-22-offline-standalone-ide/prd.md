# Complete offline standalone IDEs

## Goal and authorization

Preserve the complete user goal: make the standalone language apps useful offline IDEs with executable OHOS teaching content and polished editing/workspaces. User explicitly authorizes writing Trellis then implementing autonomously, up to four collaborators, conventional commits and pushes when available. This overrides repeated planning/commit approval prompts in local templates. Do not declare the umbrella complete from C/C++ evidence alone.

## Confirmed baseline (2026-10-22)

This is qfli_c, depending on sibling qfli_studio_core. There are 200 app-owned paired tutorials/examples (100 C + 100 C++). October 16 phone reports are historical, not proof of current artifacts. Prior terminal/startup changes are dirty at entry; preserve and audit separately. Shared core is clean at entry and must have a single writer. Current C/C++ tools use three tabs.
