# Design

Build a Trellis manifest and classify tracked, untracked, ignored, and machine-local files. Preserve evidence with its actual source commit/date. Replace stale unpublished claims only after current remote/run evidence exists.

Store durable operational rules in tracked entrypoints. Keep .trellis/.runtime and identity files ignored. Record task ownership and resume instructions in the parent handoff. Resolve the old underscore core path versus new hyphenated sibling across manifests, lockfile, and CI preparation.
