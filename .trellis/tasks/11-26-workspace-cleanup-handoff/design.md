# Design

Use fast-forward-only synchronization and compare Git object trees plus worktree status. Include untracked/ignored candidate classification so clean Git status is not mistaken for storage cleanliness. Check path dependencies without pub get.

Herdr identity is resolved from pane metadata and cwd, never sidebar order. Send exact source/destination SHAs, evidence paths, rule locations, open gates, and cleanup inventory. Require acknowledgement before retiring the old coordinator.

Preserve rollback references until equality is proven. Removing WSL distributions, compacting disks, and clearing shared SDK caches are separate ownership-scoped operations. Never invoke blanket recursive deletion or git clean -fdx.
